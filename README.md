# 🚀 Misión Múltiplo

**Misión Múltiplo** es un juego educativo interactivo para practicar el **mínimo común múltiplo (MCM)** y el **máximo común divisor (MCD)** con estudiantes de segundo grado de secundaria.

Fue diseñado para proyectarse en el aula y convertir la resolución de problemas matemáticos en una misión espacial por equipos. La propuesta se relaciona con el campo formativo **Saberes y Pensamiento Científico** de la Nueva Escuela Mexicana (NEM).

## 🎯 Propósito educativo

Que las y los estudiantes:

- Distingan cuándo una situación se resuelve mediante MCM o MCD.
- Calculen el MCM y el MCD de distintos números.
- Interpreten problemas de coincidencias, ciclos y repartos equitativos.
- Expliquen y comparen sus estrategias de solución.
- Participen colaborativamente en la toma de decisiones.

## 🎮 ¿Cómo se juega?

1. Se forman de **2 a 4 equipos**.
2. Cada equipo escribe su nombre y responde un reto por turno.
3. El juego presenta **9 preguntas distribuidas en tres rondas**:
   - **Ronda 1:** identificar si se utiliza MCM o MCD.
   - **Ronda 2:** calcular el resultado correcto.
   - **Ronda 3:** resolver problemas contextualizados.
4. Las primeras rondas otorgan **10 puntos** por respuesta correcta y la ronda final **20 puntos**.
5. Después de cada respuesta aparece una explicación para reforzar el procedimiento.
6. Al terminar, el marcador anuncia al equipo ganador.

## ✨ Características

- Diseño optimizado para proyectores y pantallas grandes.
- Modalidad de 2, 3 o 4 equipos.
- Marcador automático por turnos.
- Retroalimentación inmediata y explicaciones.
- Modo de pantalla completa y sonidos opcionales.
- Atajos de teclado con las teclas **1, 2, 3 y 4**.
- Diseño adaptable a computadoras, tabletas y teléfonos.

## 🧑‍🏫 Sugerencia para el aula

Antes de seleccionar una respuesta, el docente puede pedir que cada equipo explique por qué corresponde utilizar MCM o MCD. Así, el juego funciona también como una actividad de argumentación matemática.
